## 使用规则

- 只保留适用于当前任务的模板和字段。
- 输出规格只继承用户或上游明确值；未指定时可以推荐，但必须标记为推荐而非默认。
- 每次选择一个主创作分支，不堆叠多套完整外观。
- 先写可观察、可执行规则，再写抽象气质词。
- 所有人物、地点、台词、建筑和事件保持原创，不出现任何现成创作者、作品、角色或专有名称。
- 真人实拍输出必须先选定 `palette-atlas.md` 的一个分支，并把完整色板直接写进最终提示词前半段。用户只说“写实”“经典”或“秩序感配色”时，回退到糖果粉、丁香紫、深酒红、奶油黄、巧克力棕和淡青蓝的强识别组合，不使用低饱和米棕平均方案。

### 真人实拍色板强制块

以下块必须填充具体内容后写入图片、场景、分镜和视频提示词，不输出占位符：

```text
色彩脚本：{主色名与 HEX} 覆盖{墙面/地面/天空等位置和面积}；{辅色名与 HEX} 用于{结构位置和面积}；{人物识别色名与 HEX} 用于{服装位置和面积}；{信号色名与 HEX} 只用于{关键道具和面积}；{稳定暗色名与 HEX} 落在{木材/皮革/门窗/阴影}。颜色鲜明成块，不统一降饱和；通过{灰泥/漆木/织物/木材}的哑光质感、胶片高光和{冷暖光关系}保持写实，避免粉彩玩具感。
```

色板必须靠近提示词前部，并在多镜头 `palette_anchor` 中重复一次；不要只把 HEX 留在分析过程或参考文档里。

## 参考图职责与保护

多图先输出内部职责映射，再生成最终提示词：

```yaml
reference_roles:
  ref_01: {身份与五官 / 服装与道具 / 场景与构图 / 材质光线配色 / 动作与镜头}
  ref_02: {...}
```

冲突优先级：用户明确指令与 `preserve` ＞ 身份和主体关系 ＞ 服装道具文字 ＞ 构图动作 ＞ 场景空间 ＞ 风格材质光线配色。

默认保护块：

```text
参考职责：{逐张说明负责什么，不无差别融合}
必须保留：主体身份、人数、关系、核心外形、关键道具，以及用户列入 preserve 的内容。
允许改变：仅限用户在 creative_direction 中明确授权的服装、场景、时代、配色、媒介、动作、构图或光线。
未授权维度：保持参考输入稳定，不新增、删除或替换设定。
```

用户没有提供允许改变项时，执行稳定优先。用户明确要求换装、换场景、换时代或重新配色时，开放对应维度，不让默认保护覆盖用户指令。

## 文生图

```text
生成{交付物与媒介}。原创{主体、人数与关系}正在{一个具体叙事动作}，位于{地点与时代状态}。

创作分支：{主分支}；仅借用{可选的单一相邻机制}。使用{正面平视/完全侧面/正俯拍}机位和{中轴/横向剖面/单点透视/网格}构图；前景{元素}，中景{主体与动作}，后景{门窗/走廊/格柜/地平线}形成{水平/垂直/纵深}秩序。唯一叙事性破格是{空位、错误物件、偏轴道具或越轴视线}。

色彩关系：{环境基底色及面积}、{结构辅色及面积}、{人物识别色}、{小面积道具信号色}、{天空/阴影色}；说明颜色的空间分配与叙事作用。光线由{来源}从{方向}进入，{硬度}，{阴影形态与补光量}，{冷暖或黑白明度关系}。实体{材质列表}保持触感，{景深与成像质感}。人物以{视线、站姿、握持或微动作}透露{隐藏情绪}。

连续性锚点：{角色、场景、材质、光线、镜头与道具}。
输出规格：{只继承用户或上游明确值}。
```

真人实拍路径必须在最终提示词前半段写入一套完整的 5–8 色视觉近似 HEX 色板，逐色说明落点、面积和材质；不得只写色名、综合色倾向或“受控配色”。颜色关系必须形成明确主次：环境主色约 35%–50%，结构辅色约 15%–25%，人物识别色约 10%–20%，道具信号色通常不超过 10%。同时写明“颜色鲜明成块，不统一降饱和”，再用灰泥、漆木、织物、木材和胶片高光抑制数码刺眼。实体定格默认只写自然语言色彩关系；用户明确要求色值时才输出已有 HEX。

## 连续性块

```yaml
continuity_lock:
  character_anchor: ...
  scene_anchor: ...
  material_anchor: ...
  light_anchor: ...
  camera_anchor: ...
  motion_anchor: ...
  prop_anchor: ...
```

真人实拍必须增加：

```yaml
  palette_anchor: "所选分支的 5–8 个具体 HEX；逐色记录空间落点、面积、材质载体、冷暖光影响与禁止漂移的杂色"
```

该锚点必须在逐镜头提示词中落实，不能只放在整体设定。

实体定格默认不加入 HEX `palette_anchor`；用户明确要求色值或跨媒介统一时除外。

## 负面约束

只选择最可能破坏当前方案的项目，不堆砌无关通用词。

真人实拍：

```text
避免插画、卡通、光滑 3D、塑料玩具、无依据霓虹、色板外数码渐变、随意斜机位、浅景深光斑、过强 HDR、强镜头炫光、过度锐化、夸张表情、乱码文字、身份漂移、道具复位、空间重构和任何现成影视资产复现。
```

实体定格：

```text
避免光滑商业 CG、镜面塑料毛发、数字流体、无轴线构图、无依据背景虚化、霓虹杂色、肢体融化、木偶比例漂移、身份变化、道具复位和任何现成角色复现。
```

视频追加：

```text
避免手持乱抖、自由环绕、无人机穿越、持续旋转、同镜头多重运镜、跳轴、空间漂移、人物瞬移、服装道具变化、动作结果复位、光源反转和背景无故重构。
```

## 规格推荐

以下只在匹配题材且用户未指定规格时作为建议，不能静默写成默认值：

- 超宽画幅：适合横向建筑立面、队列、车厢、船体剖面和沙漠地平线。
- 近方形画幅：适合纵向站姿、门框套层、舞台框景、单人或双人谈判。
- 短视频：建议只保留一个清楚计划、一次破格和一个可继承的结束状态。
- 较长视频：可以增加程序升级、关系转折和情绪余韵，但镜头数由用户规格和叙事需要决定。
- 主体尺寸：确保主体可读并与空间制度建立关系；任何百分比都只能作为当前构图建议，不是全局规则。
