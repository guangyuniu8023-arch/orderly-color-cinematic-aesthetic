## 核心戏剧机制

故事动力不是“古怪人物摆造型”，而是角色试图用秩序处理无法被秩序解决的感情。

1. **建立小世界**：家庭、学校、探险队、列车、旅馆、编辑部、剧团或商业网络拥有职位、制服、流程和礼仪。
2. **建立角色计划**：主角擅长策划、分类、表演或管理，确信一个具体方案能修复名誉、家庭、爱情、事业或失去。
3. **制造破格**：信件、死亡、继承、偷窃、禁令、访客、天气、失踪或错误物件打乱制度。
4. **程序化升级**：列清单、画地图、召集团队、换制服、搭交通工具、连续拜访；程序越精确，情感漏洞越明显。
5. **付出现实代价**：关系破裂、公开失败、受伤、被捕、失去物件或面对旧创伤。
6. **作出情感选择**：角色放弃部分控制，完成一个比原计划更诚实的可见动作。
7. **留下苦甜余韵**：秩序被部分恢复，但损失不被抹去。

## 叙事容器

| 容器 | 结构 | 适合主题 | 视觉组织 |
| --- | --- | --- | --- |
| 线性计划 | 计划—排练—执行失败—临时补救—关系结果 | 野心、友谊、失败 | 地图、清单、装备俯拍、横向行动 |
| 家族群像 | 人物档案—重聚—旧矛盾—外部危机—不完整和解 | 父母缺席、手足、遗憾 | 房间剖面、人物色彩编码、群像站位 |
| 旅程 | 出发—站点遭遇—行程中断—面对失去—改变目的地 | 成长、逃离、哀悼 | 车厢横移、地图、行李、慢动作转折 |
| 任务救援 | 小队组建—规则训练—连续关卡—代价—集体行动 | 责任、社区、亲子 | 队列、剖面基地、程序蒙太奇、追逐 |
| 档案回忆 | 外层讲述—文章/书页—内层行动—返回讲述现场 | 历史、艺术、失去 | 章节卡、黑白/彩色切换、静止群像 |
| 舞台元叙事 | 主持介绍—戏中戏—后台插入—角色与演员互照 | 哀悼、创作、未知 | 舞台框、换景机关、直面镜头、层级切换 |

不要自动选择最复杂的结构。短视频优先一个清楚计划和一次破格；只有题材涉及记忆、出版、舞台或创作时才使用嵌套叙事。

## 分镜职能

1. **制度建立**：正面全景展示整个空间、队列或建筑。
2. **角色档案**：正面中景或全身，角色与身份物件同框。
3. **程序蒙太奇**：短镜头呈现列清单、穿制服、装箱、盖章、校准或排队。
4. **俯拍目录**：地图、信件、钥匙、工具或证物按网格排列，一只手改变其中一项。
5. **横向揭示**：摄影机沿船舱、列车、走廊或街道匀速横移。
6. **破格反应**：一次甩镜、突然轴向推进或静止近景连接错误与反应。
7. **情绪余韵**：锁定群像、空房间或离开的交通工具，让损失通过位置和物件显现。

每个镜头使用以下状态闭环：

```text
镜号与剧情职能：
起始状态：人物位置、朝向、姿势、服装、道具、环境和光线。
主体动作：准备—主要动作—动作结果—停顿或衔接。
环境响应：道具、门窗、群演、尘土、布景机关、光影或声音反馈。
镜头运动：起始景别与机位、唯一路径、速度、停止位置和结束构图。
结束状态：人物站位、朝向、姿势、道具位置和环境变化。
连续性继承：下一镜头必须继承的身份、服装、道具、轴线、光源和时间状态。
台词/旁白/声音：
转场与潜台词：
```

## 运镜与剪辑

| 运镜/剪辑 | 正确用途 | 避免 |
| --- | --- | --- |
| 锁定机位 | 建立制度、等待、显示细小表演 | 没有画面调度的僵硬静止 |
| 匀速横移 | 展开剖面空间、流程和并列人物 | 无目的左右摇摆或高速穿越 |
| 轴向直推/直拉 | 从公共秩序进入私人反应 | 斜向漂移、反复呼吸式推拉 |
| 一次甩镜 | 连接同一空间的命令、错误与反应 | 连续炫技、模糊中没有落点 |
| 正俯拍插入 | 让道具成为证据、计划或关系线索 | 只做漂亮静物而不改变剧情 |
| 垂直升降 | 连接楼层、层级、监禁或逃脱结构 | 没有空间标志的升降展示 |
| 慢动作 | 离别、错过、奔跑或章节尾声 | 把每个动作都浪漫化 |
| 匹配切 | 用形状、位置、物件或动作跨越时空 | 不保持方向、角色和道具状态 |

## 台词、旁白与声音

- 使用完整、精确、略正式的句子；在时间、金额、编号、职位和物件上给出具体信息。
- 让语言来自身份：管理员讲流程，学生讲计划，记者讲观察，商人讲条件。
- 使用“礼貌长句—突然直白短句”的节奏；真正的情绪句更短。
- 让人物平静描述严重问题，让小问题被当作重大程序故障。
- 允许打断、重复、纠正称呼、停顿和答非所问，但要暴露权力或感情。
- 旁白负责过去、制度和时间跨度，画面负责当下动作。
- 声音与动作同步：纸张折叠、钥匙落盘、门闩闭合、车轮、脚步、机械机关和远处广播都应有明确来源。

原创台词构造：

```text
角色目标：此刻想让对方做什么？
公开措辞：如何用职位、礼仪或技术语言包装请求？
隐藏情绪：害怕失去什么，或不愿承认什么？
反差落点：最后一句如何突然缩短、改称呼或承认事实？
配套动作：整理、递交、校正、折起或越过中轴看人。
```

## 原创故事方法

写作前确定：

1. 谁为了什么执行什么计划，什么意外迫使其改变？
2. 小世界的地点、制度、职位、制服和流程是什么？
3. 主角的外在专长与内在缺口是什么？
4. 主角最想控制或修复哪段关系？
5. 哪件道具会被递交、遗失、调包、保存或破坏？
6. 秩序色、角色识别色和破格信号色如何变化？
7. 最后一个可见动作是什么？

短片结构：

```text
开场：正面稳定构图建立世界规则。
触发：物件、消息或闯入者破坏程序。
计划：主角通过清单、地图或队伍提出方案。
升级：两至三次程序动作增加代价和关系压力。
转折：具体失败迫使主角面对真实情感。
选择：完成一个可见、不可撤回的小动作。
余韵：制度部分恢复，空位或旧物保留损失。
```

## 常见失败

| 失败 | 原因 | 修正 |
| --- | --- | --- |
| 只有对称画面，没有故事 | 把美学当静态布景 | 增加限时计划、关键道具和真实失败 |
| 角色只是“古怪” | 没有职业能力与情感缺口 | 写清角色维护什么秩序，以及秩序掩盖什么恐惧 |
| 每个故事都使用多层旁白 | 把一种变体误当全局规则 | 短片优先线性计划，按题材决定是否嵌套 |
| 台词全是俏皮话 | 缺少角色语域和潜台词 | 让大多数台词完成真实任务 |
| 旁白重复画面 | 声画没有分工 | 旁白说过去与制度，镜头呈现当下动作 |
| 运镜很多但没有节奏 | 一镜多重运动且没有落点 | 一镜一职能一主运动，明确开始与结束构图 |
| 道具和颜色不改变剧情 | 画面只是广告陈列 | 让关键物件被递交、调包、遗失或留在空位上 |
